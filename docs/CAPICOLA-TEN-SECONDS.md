# Capicola ten-second capacity experiment

Revision 1, 2026-10-07. Authorized by the user's request to do the necessary capacity work and assess ten seconds. Lane: source reimplementation; existing AGPL-3.0 Capicola lineage and pinned dependencies unchanged. Working artifact is a bounded mono C99 bank/reader plus host and standalone SHARC reports. No firmware integration or device upload.

## Selected architecture

EVIDENCE: the current core embeds 4096 keyframes in each reader and limits input to 48000 frames. Its two-limb duration product is only safe at that length. INFERENCE: ten seconds is a reasonable next bounded prototype, provided storage and arithmetic change together. UNRESOLVED: actual firmware memory ownership and hardware deadline margin.

Allow 480000 input frames at 48 kHz (ten seconds), up to 960000 output frames at advance 0.5. Preserve Q24 timestamps, pitch/source advance 0.5–2, leash 16–128, splice policy, edge ramp and normalized finite input. Keep the original core, split core, oracle and all their contracts untouched.

Separate an immutable analyzed sample bank from each reader. Bank metadata refers to caller-owned arrays of float value, int whole and unsigned fractional time. Provide a count-only analysis pass, then let the caller allocate exactly 12 bytes per keyframe and load the bank. No allocator, file access or copying in the audio callback. Bank and arrays must outlive every bound reader. Loading/rebinding a bank is a serialized control operation, never concurrent with rendering; increment a generation counter to silence previously bound readers after replacement. On wrap, skip zero; callers must retire readers before 2^32 bank mutations. Reset/stop a reader does not modify the bank. Two readers can share a bank with independent pitch/transport.

A structural upper bound is frames+4 keyframes: the analyzer considers only frames+4 iterations and emits at most one each. Thus capacity 480004 admits every valid bounded input, without discarding dense details. This is a conservative maximum of 5,760,048 bytes (5.49 MiB) per distinct sample, not a per-reader reservation. The count pass permits smaller allocations for sparse musical input. Temporary float input adds 1,920,000 bytes (1.83 MiB) while loading and is not retained by the bank. Limit caller capacity to 480004; undersized storage returns overflow and clears readiness, with no out-of-bounds writes. No automatic growth during playback. Initial caller arrays must be nonoverlapping, suitably aligned and sized to the declared capacity; ownership is external.

Replace duration multiplication with three 8-bit limbs: accumulate each limb product and carry, then return floor(n*rate/2^24). For n<=960000 and rate<=2*2^24 each intermediate is below 2^28. Binary-search the first output count whose exact product reaches input length. Do not change division/interpolation or the known target analyzer discrepancy in this capacity slice.

## Equivalence and validation

Reference: preserved double core built from a scratch copy with only MAX_INPUT and CAPACITY macros expanded to 480000 and 480004. Record original and adapted hashes; never edit the originals. The original one-second split core remains a compatibility comparator. Host amplitudes/counts exact, times within 2^-24 sample, PCM max 1e-4 / RMS 1e-5, finite and input-peak bounded plus 1e-6. No relaxed tolerances.

Host tests: ten-second silence, impulse at 9.5 seconds, sine, two-tone, drums and seed-1 xorshift noise; controls 1/0.7,0.7/1,1.1/0.7 plus extremes 0.5/2 and 2/0.5. Count/allocate/load parity, minimum input, 480000 accepted and 480001 rejected, capacity exact-fit and one-short with guards, no truncation, failed-load silence, independent shared readers, replacement invalidation, stop/retrigger/partition equality, deterministic random duration cases and a negative test reproducing old duration overflow. Long dense signals must exceed the former 4096 and 40960 capacities and still load with measured storage.

Target: compile the new reader, check bank/reader layouts, place bank arrays in a separate disjoint emulator test arena (not claimed firmware-owned RAM). Full ten-second sine source rendered at pitch 0.7/advance 2, exact repeat and PCM comparison. Bounded 4096-frame dense-noise windows at start and near the sample end exercise large indices and external storage. Tail windows seeded from explicit host reader states test up-to-20-second output stops at decimal and boundary rates; these are seeded window tests, not continuous target histories. Validate target duration independently for selected boundary rates, guard buffers, generation invalidation and report instruction counts. Existing SINE replay and configured harness suite must pass. Preserve the prior target analyzer gap separately; host analysis supplies this slice's target keyframes.

Results: unique ignored out/runs directories, report.json, source hashes, float PCM and WAV output. Notes: CAPICOLA-TEN-SECONDS-RESULTS.md and capacity-contract RESULTS/GAPS. Quality versus stock STRETCH, stereo, loops/reverse, multiple distinct banks in a firmware pool and physical timing remain deferred.
