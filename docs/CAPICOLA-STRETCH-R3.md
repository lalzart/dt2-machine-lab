## Exact live transition policy

One current and one outgoing CapStretch per lane; banks are immutable and shared. On a valid PLAY or bounds change during an active note, derive absolute source position from the current ideal Q24 cursor (normalize by old region length for looping), using old forward start+x or reverse end-1-x. Clamp that source position to [new_start,new_end-1], then convert it to new direction-relative Q24 position. Initialize the new reader on the same bank with the new region/mode/rates. Seed its ideal, actual and incoming positions identically at that position, with initial entry fade already complete (position=48). Recompute finite remaining duration exactly. The old reader continues as outgoing for 64 output samples. Mix outgoing*(1-smooth(t)) + current*smooth(t), t=completed/63, smooth=t*t*(3-2*t), with first weight zero and last one. No sample copies, bank analysis or allocation in the renderer. This is a deliberate Capicola transition policy, not a claim of bit-exact stock grain behavior.

During a transition, keep only the latest requested region/mode; start it when the current 64-sample transition finishes. Returning to the current configuration cancels the pending change. TUNE/advance update both readers each block without resetting cursors; rates accompanying queued changes are latest. Finite completion never resurrects a note. Invalid controls or retired bank generations stop both readers before key access. Native trigger restarts normally and clears pending/fade state. Native source/machine invalidation stops both; no mid-note stock takeover.

CapLive target size 256 bytes, lane size 276 bytes, 32 lanes 8832 bytes. Place live lanes at logical 0x200e8000..0x200eb000 and renderer trace at 0x200eb000..0x200ec000, within the existing 200 KiB working region. Cache remains 0x200e7000..0x200e7800. Reservation 8 MiB and preparation budget 32 positions per normal block are unchanged. Both current/outgoing banks remain pinned while active.
