# Archived experiment reports

These are dated observations and superseded designs, not current build recipes
or task instructions. Start with [current status](../STATUS.md),
[the documentation map](../README.md), and [Capicola](../CAPICOLA.md).

The older Capicola reports concern different engines from the current author
port. Original artifacts and verification records remain preserved. JSON records
retain their original paths and hashes as historical provenance; the table below
maps moved documents. Frozen proposal documents stay at their original locations
because explicit historical checks authenticate their bytes.

The unused `scripts/probe-capicola-target.py` and
`scripts/probe-capicola-stretch-path.py` were removed on 2026-10-28. References to
them inside dated reports are historical; their source is recoverable from Git
and the local cleanup snapshot described in [cleanup notes](../REPO-CLEANUP-2026-10-28.md).
