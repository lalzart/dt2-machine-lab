## Full playback behavior and explicit sample-host seam

The source module is a live-input processor as well as recorder; a loaded Digitakt sample is an immutable finite object. A literal live-writer fence at the end with a start at zero immediately invokes the source's back-edge rescue to the end. Instead use a virtual periodic sparse medium made from the selected region: one synthetic key at each region boundary with the source's value at the first traversal sample, plus all source extrema strictly inside that traversal period. Both reading heads can cross region boundaries without being replaced by zero or receiving independent edge gain dips. One-shots stop when the IDEAL cursor reaches selected duration; loops repeat indefinitely. Thus clip transport, not a read-head boundary, controls note completion. This seam is tested by materializing the identical periodic keyframe medium in the actual unmodified upstream SparseLine/Granule; writer guards are out of reach. This is an explicit finite-file adaptation, not a claim that the Eurorack live input/feedback interface is implemented.

At48kHz, ideal+=advance; actual/temp+=pitch. Rank distance beyond128 keyframes triggers original Granule adaptive splice: temp=ideal; duration=key(grid-1)-key(grid-leash) when actual lags; otherwise key(grid+leash-1)-key(grid-1). Minimum48 source samples. No maximum fade, no one-period cap, no source-edge fade cap. During splice y=temp*smooth(phase)+actual*(1-smooth(phase)), phase+=(1/duration)*pitch. Preserve float arithmetic order. Keep2^-22 minimum step solely to prevent binary32 phase stalling; no impact in declared comparison cases. No per-grain gate or inserted silence, no independent48-sample entry/exit/loop attenuation. Native amp envelope owns note gain. Sparse waveform interpolation preserves upstream two-point smooth Hermite, despite source CATMULLROM enum.

Dual-grain handoffs use upstream module fixed fade960 output samples. Retrigger, direction and trim changes allow the outgoing grain to finish at its previous rates while incoming follows new controls. Initial trigger has no redundant Core fade; native envelope remains. Rapid region changes queue until the existing handoff ends to avoid discarding an audible grain. Stop/source invalidation silences both immediately and never resumes stock mid-note. Init deterministically clears all histories. Native selector2/TUNE/BARS/STRT/LEN/PLAY and CAPI encoderC, locks and backend feedback preserved; source fidelity chosen over instruction savings. No render sharing, auxiliary removal, cadence throttling or trace removal introduced.
